# Giro — Trasferimenti

App dimostrativa: invia, chiedi e dividi le spese con gli amici, e scrivi in chat. Il saldo e i trasferimenti sono simulati: nessun pagamento reale viene effettuato.

**Apri sul telefono:** https://filideicristian21-tech.github.io/giro/

Per ora si entra con **Entra con nome**. I pulsanti Google e X restano in configurazione finché non si compilano i valori in `firebase-config.js` (guida in `SETUP.md`).
